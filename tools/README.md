# tools

리습과 함께 쓰는 외부 프로그램 설치 파일(zip/exe/msi)을 두는 폴더입니다.
50MB가 넘는 파일은 GitHub Releases에 올리고 catalog의 설치 파일 칸에 https 주소를 적으세요.

## 구버전 보관 (런처 미사용자용)
MATX·PAVQ 는 이제 CAD런처.exe 안에 매핑 엔진이 내장되어 있어, catalog.json 에는
이 zip들이 더 이상 연결되어 있지 않습니다 (런처 사용자는 설치할 필요 없음, "외부 프로그램 설치" 버튼이 뜨지 않음).
런처를 쓰지 않고 예전처럼 보조 프로그램을 따로 받아 쓰던 사용자를 위해 구버전을 그대로 보관합니다.

- `MATX-Tools.zip` (v1.0) — mapping_engine.exe, run_after_matx.bat, 자재내역.xlsx
- `PAVQ-Tools.zip` (v0.9) — PAVQ_FORM.exe, 복구수량산출서_양식.xlsx
