# CAD 런처 (AutoCAD LT 2026용)

리습 명령을 버튼처럼 실행하고, 옵션을 조정하고, 설명서를 바로 보는 외부 프로그램입니다.
설치할 것은 없습니다 (Windows 10/11 64비트).

## 구성
```
CAD런처/
├─ CAD런처.exe           프로그램
├─ catalog.json          리습 목록 (기능 분류 › 리습 › 명령어, 설명서, 옵션)
├─ lsp/
│  ├─ GGv2.lsp           도곽 기준 기술검토 자동 정리
│  ├─ BPDF.lsp           도곽별 PDF 일괄 출력
│  └─ launcher_opt.lsp   옵션 전달 헬퍼 (지우지 마세요)
├─ tools/                리습과 함께 쓰는 외부 프로그램 설치 파일 (있을 때)
├─ dev/register.py       새 리습을 목록에 등록하는 스크립트 (관리용)
├─ src/                  프로그램 소스 (실행에는 필요 없음)
├─ launcher_state.json   이 PC의 설정·마지막 옵션값 (자동 생성, 저장소에 올리지 않음)
└─ _backup/              업데이트 전 파일 보관 (자동 생성)
```

## 사용
1. `CAD런처.exe` 실행 → AutoCAD LT를 켠 상태에서 **창 찾기**
2. 왼쪽 목록에서 **기능 분류 › 리습 › 명령어** 선택 → 오른쪽 **설명서** 확인
3. 옵션이 있는 명령은 값을 조정 → **▶ 실행** (명령어 더블클릭도 실행)

- 옵션이 없는 명령은 옵션 칸이 비어 있고 설명서만 보입니다.
- 실행이 안 되면 위쪽 **전송 방식**을 `키입력`으로 바꿔 보세요.
- 리습 파일은 바뀌었을 때만 다시 불러옵니다. 그래서 FORMSETAREA 처럼 실행 중에 바꾼 설정이 유지됩니다.

## 목록 편집
| 버튼 | 동작 |
|---|---|
| 분류 추가 | 기능 분류 만들기 |
| 리습 추가 | 리습 파일 선택 → 파일 안의 `(defun c:이름)` 명령을 자동으로 등록 |
| 명령 추가 | 선택한 리습에 명령어 추가 |
| 편집 | 선택한 항목의 이름·설명·설명서·옵션 수정 (리습은 분류 이동도 가능) |
| 삭제 | 목록에서만 제거 (파일은 그대로) |
| ▲ ▼ | 같은 단계 안에서 순서 변경 |

### 옵션 연결 방법
- **LISP 변수 연결 (권장)**: 옵션 편집에서 `LISP 변수`에 `*TEE-RADIUS*` 처럼 리습의 전역 설정 변수를 적으면, 실행할 때 `(setq *TEE-RADIUS* 값)`을 보낸 뒤 명령을 실행합니다. **리습을 고칠 필요가 없습니다.**
- **옵션 파일 방식**: LISP 변수를 비우면 값을 `%TEMP%\cad_launcher_opt.txt`에 저장합니다. 리습에서 `(LO:take "명령어")`, `(LO:get "키" 기본값)`으로 읽습니다.
- 리습 함수 안에서 `setq`로 정해 둔 값(예: BPDF의 출력 설정)은 LISP 변수로 바꿀 수 없습니다.

## 외부 프로그램 (리습 + 프로그램 세트)
리습이 별도 프로그램과 함께 동작하는 경우, 리습 편집 창의 **외부 프로그램**에 등록해 둡니다.
그러면 런처에서 그 리습을 고를 때 **외부 프로그램 설치** 버튼이 보이고, 실행 전에 설치 여부도 확인합니다.

| 종류 | 설치 방법 |
|---|---|
| zip | `%LOCALAPPDATA%\CADLauncher\tools\이름\`에 압축을 풉니다 (관리자 권한 필요 없음, 권장) |
| file | 파일 하나를 같은 폴더에 복사합니다 |
| exe / msi | 설치 프로그램을 실행합니다 (설치 옵션 예: `/S`, `/quiet`) |

- **LISP 변수**에 `*MATX-EXE*`처럼 적어 두면, 실행할 때 설치된 프로그램 경로를 그 변수로 리습에 넘깁니다.
- **버전**을 올리면 이미 설치한 PC에 '새 버전 있음'으로 표시됩니다.
- 설치 파일은 저장소의 `tools/` 폴더에 둡니다. 50MB가 넘는 파일은 GitHub **Releases**에 올리고 그 https 주소를 적으세요. (저장소에는 100MB 넘는 파일을 올릴 수 없습니다)

## 리습 머리말 (@launcher) — 새 리습 바로 등록
리습 파일 맨 위에 아래처럼 적어 두면, **리습 추가**로 파일만 고르면 분류·설명·명령·설명서·옵션·외부 프로그램이 자동으로 채워집니다.
```lisp
;;; @launcher
;;; 분류: 도면 검수
;;; 이름: MATX
;;; 설명: 평면도·종단·자재내역 수량 대조
;;; 명령: MATX | 수량 대조 실행
;;; 명령: MATXDEL | 대조 표시 지우기
;;; 옵션: MATX | *MATX-TOL* | 허용오차 | number | 0.5 | 단위 m
;;; 외부프로그램: MATX뷰어 | tools/MATXView.zip | zip | MATXView.exe | *MATX-EXE* | 1.0
;;; 설명서:
;;;   여러 줄 설명은 두 칸 들여쓰기
;;; 명령설명서: MATX
;;;   명령별 자세한 설명
;;; @end
```
- 옵션: `명령 | LISP변수 | 표시이름 | 종류(text/number/int/check/choice/file/folder) | 기본값 | 도움말`
- 외부프로그램: `이름 | 설치파일 | 종류(zip/exe/msi/file) | 실행파일 | LISP변수 | 버전 | 설치옵션`
- 저장소에서는 `python dev/register.py lsp/새리습.lsp`로 같은 규칙에 따라 `catalog.json`에 등록합니다.

## GitHub 자동 업데이트
1. 업데이트 저장소는 `hsb6582/cad-launcher`(공개)로 프로그램에 고정되어 있습니다. **업데이트 설정**에서는 자동 확인 켜기/끄기만 바꿀 수 있습니다.
2. 런처를 켤 때마다(또는 **업데이트 확인**을 누를 때) 저장소와 비교합니다.
   바뀐 파일(`lsp/`, `catalog.json`, `CAD런처.exe`, `README.md`)만 내려받고, 기존 파일은 `_backup/날짜/`에 보관합니다.
3. 이 PC에서 직접 고친 파일은 덮어쓰기 전에 따로 물어봅니다.
4. 런처 자신이 바뀌면 교체한 뒤 다시 시작할지 묻습니다.

**리습을 고쳐서 배포하는 순서**: 저장소의 `lsp/파일.lsp`(필요하면 `catalog.json`도)를 고쳐서 올립니다. 그러면 각 PC의 런처가 다음 실행 때 자동으로 받습니다.
런처에서 목록을 편집했다면 바뀐 `catalog.json`을 저장소에 올려야 다른 PC에도 반영됩니다.

## 소스 수정 후 다시 빌드 (선택)
Go 설치 후 `src` 폴더에서:
```
set GOOS=windows& set GOARCH=amd64& go build -ldflags "-H windowsgui -s -w" -o CAD런처.exe
```
